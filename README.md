# Face & Eye Detection

A beginner-friendly computer vision project built with Python and OpenCV. 
The program uses a webcam to detect human faces and eyes in real time.

## 🎯 Project Goal

The goal of this project is to learn the fundamentals of:

- Python
- OpenCV
- Computer vision
- Image processing
- Face detection
- Eye detection
- Real-time webcam processing

## 🛠️ Technologies Used

- Python
- OpenCV
- Git & GitHub

## 📌 Features

- Real-time webcam video
- Face detection
- Eye detection
- Bounding boxes around detected faces and eyes
